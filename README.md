# LOGINOFGAMES
Uma ideia parecida ao "acessar a conta da steam"

Nome do Projeto: Login of Games;
Integrantes: Heitor, Allan, Ruben, Ygor.


Descrição: O sistema foi feito em Python para facilitar o cadastro e o gerenciamento de usuários. Ele possui quatro funções principais: cadastrar, consultar, atualizar e excluir. Dessa forma, é possível adicionar novos usuários, ver os dados cadastrados, alterar alguma informação quando necessário e também excluir um cadastro. A ideia foi criar um sistema simples, mas que mostrasse como funciona um CRUD na prática.

Tecnologias utilizadas: SQLserver.

Como executar o projeto: Para executar o projeto, basta ter o Python instalado, abrir a pasta no VS Code e executar o arquivo  sistema.py. Depois, é só escolher uma das opções do menu e seguir as instruções.
